# Entscheidungen

- All-Inkl/WebMail ist aktueller Zielkontext; SOGo ist historisch/kompatibel, aber nicht mehr allein maßgeblich.
- Automatische Verarbeitung von Spam/Junk/Trash/Drafts/Archiv bleibt ausgeschlossen.
- Backfill bestehender INBOX-Nachrichten bleibt explizit opt-in.
- Zugangsdaten werden nur in Thunderbird/Add-on-Konfiguration gespeichert, nicht im Repo.
